# TC 備份伺服器安裝包

號誌控制器參數版本歷史的資料中心端備份伺服器（Gitea，Windows 免安裝版）。
本 repo 只提供下載，**沒有原始碼**。

- 下載最新版：[TC-Backup-Server.zip](https://github.com/IISI-2508006/tc-backup-installer/releases/latest/download/TC-Backup-Server.zip)
- 解壓後雙擊「啟動TC備份伺服器.bat」，之後在背景執行、登入 Windows 自動啟動。
- 使用說明在 zip 內的 `docs\使用手冊_控制中心.md`。
